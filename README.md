### Requirements

- CUDA capable GPU
- Must have Conda installed. Create a new environment using:
  ```bash
  > conda env create --name slime-mold --file=setup/conda-env.yml
  > conda init
  ```
- Pygame - not installable through Conda. Run `pip install pygame`
